# Eashan SAT Vocab Trainer

Standalone SAT vocabulary game optimized for iPhone and desktop.

Public URL:

https://nahsae.github.io/trisha-offline-quiz/sat-vocab/

The app includes the full 400-word College Panda SAT vocabulary deck as the default word list.

## Modes

- Flashcards
- Multiple choice
- Type answer
- Speed match
- Import words

Progress is saved locally in the browser using localStorage.
